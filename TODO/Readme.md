## Ansible Playbook

### Установка Ansible

```bash
make init-ansible
```

Проверка синтаксиса: Перед запуском playbook убедитесь, что синтаксис корректен:

```bash
make syntax-check
```

Тестирование: Запустите playbook с флагом --check для сухого прогона:

```bash
ansible-playbook -i inventory/hosts.yml playbook.yml --check
```
